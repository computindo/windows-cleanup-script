How to run

1

Open PowerShell as Administrator

Press Windows key → type powershell → right-click → Run as administrator
2

If prompted about execution policy, run this once first

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
3

Paste the command and press Enter

The script downloads, runs all 11 sections, and exits. No files left behind.
4

Confirm prompts when asked

Recycle Bin and Windows.old will ask before deleting. Everything else runs automatically.
